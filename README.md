
# 🛡️ AEGIS-XAI

### AI-Enhanced Guard for Intelligent Security with Explainable AI

**AEGIS-XAI** is a cybersecurity learning and development project exploring AI-assisted network intrusion detection, network traffic monitoring, and explainable security analysis.

The project combines a web-based monitoring dashboard with network traffic capture, flow processing, database integration, and machine-learning components to explore how network activity can be monitored and potential security threats investigated.

## 🚀 Project Objectives

- Monitor network traffic using TShark.
- Capture packets from a selected network interface.
- Process captured traffic into network flows for analysis.
- Explore machine-learning approaches to anomaly and intrusion detection.
- Present monitoring information through a web-based dashboard.
- Display available detection events and security-related information.
- Explore explainable analysis of potential security events.

## ⚙️ Installation and Setup

### 1. Clone the repository

Open PowerShell or a terminal and run:

```bash
git clone https://github.com/ganeshanragesh/AEGIS-XAI.git
cd AEGIS-XAI
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a local `.env.local` file in the project root.

For example, the database URL may use the following format:

```env
DATABASE_URL=postgresql://USER:PASSWORD@localhost:5432/DATABASE_NAME
```

Replace the example values with your own PostgreSQL credentials and database name.

Add any other environment variables required by the project configuration.

**Security reminder:** Never commit `.env.local`, passwords, API keys, database credentials, or other secrets to GitHub.

### 4. Configure PostgreSQL

Create the database required by your configuration and perform the database setup or migration steps defined by the project.

Ensure the database is running and the connection string is correct before starting the application.

### 5. Configure TShark

Install Wireshark and confirm that TShark is available on your system.

If the application requires a specific executable path, configure it according to the project's implementation.

Select an appropriate network interface and grant only the permissions needed for authorised monitoring.

### 6. Start the development server

```bash
npm run dev
```

Open the application in your browser:

http://localhost:3000

The live monitoring dashboard is available at:

http://localhost:3000/dashboard/monitor

### 7. Validate the application

If the corresponding scripts are defined in `package.json`, run:

```bash
npm run typecheck
npm run build
```

These checks completed successfully in the previously tested development environment. Successful type checking and building do not independently verify live traffic processing, detection accuracy, or every feature.
